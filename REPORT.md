# Отчет по лабораторной работе

## 7.1 Постановка задачи

Разработать программу на C++, моделирующую выборки случайных величин с заданными распределениями, вычисляющую их основные числовые характеристики и сравнивающую эмпирические результаты с теоретическими значениями.

В рамках проекта реализованы:

- нормальное распределение `Normal(0, 1)`;
- равномерное распределение `Uniform(-1, 3)`;
- сдвинутое экспоненциально-лапласовское распределение `ShiftedExponentialLaplace(shift = 0.5, scale = 1.2, form = 2.0)`.

Для каждого распределения программа:

- генерирует выборки нескольких объемов;
- вычисляет эмпирические оценки математического ожидания, дисперсии, коэффициента асимметрии и эксцесса;
- сравнивает их с теоретическими значениями;
- строит эмпирическую плотность по гистограмме;
- сравнивает значения теоретической и эмпирической плотности в заданных точках.

Дополнительно в проекте показано применение паттерна "Наблюдатель": при изменении данных гистограмма автоматически пересчитывается.

## 7.2 Алгоритм, описание и текст разработанной программы

### Структура программы

Программа находится в файле `main.cpp` и включает следующие основные сущности:

- интерфейс `IDistribution` задает общий контракт распределения: `density`, `randNum`, `mean`, `dispersion`, `asymmetry`, `excess`;
- интерфейс `IPersistent` описывает сохранение и загрузку параметров распределения;
- классы `Normal`, `Uniform`, `ShiftedExponentialLaplace` реализуют конкретные распределения;
- класс `Data` хранит выборку, вычисляет эмпирические характеристики и управляет наблюдателями;
- класс `Histogram` строит эмпирическую плотность по выборке и обновляется при изменении данных;
- демонстрационные функции `demoDistribution` и `observerDemo` выполняют расчеты и вывод результатов.

### Алгоритм работы программы

1. Создаются объекты распределений с фиксированными параметрами и зерном генератора `42`.
2. Для каждого распределения генерируются выборки заданных объемов.
3. Для каждой выборки вычисляются:
   - эмпирическое математическое ожидание;
   - эмпирическая дисперсия;
   - эмпирическая асимметрия;
   - эмпирический эксцесс.
4. Значения сравниваются с теоретическими характеристиками распределения.
5. Для небольших выборок строится гистограмма из 12 интервалов и вычисляется эмпирическая плотность.
6. Теоретическая и эмпирическая плотности сравниваются в нескольких контрольных точках.
7. В конце демонстрируется автоматическое обновление гистограмм при изменении данных.

### Формулы эмпирических характеристик

Для выборки `x_1, x_2, ..., x_n` используются формулы:

- математическое ожидание:

`m = (1 / n) * sum(x_i)`

- дисперсия:

`D = (1 / n) * sum((x_i - m)^2)`

- коэффициент асимметрии:

`A = (1 / (n * D^(3/2))) * sum((x_i - m)^3)`

- эксцесс:

`E = (1 / (n * D^2)) * sum((x_i - m)^4) - 3`

### Краткое описание реализации распределений

`Normal`:

- плотность вычисляется по стандартной формуле нормального распределения;
- случайные значения генерируются через `std::normal_distribution`.

`Uniform`:

- плотность постоянна на отрезке `[a, b]` и равна `1 / (b - a)`;
- случайные значения генерируются через `std::uniform_real_distribution`.

`ShiftedExponentialLaplace`:

- плотность задается через базовую функцию `BaseDensity`;
- случайные значения моделируются с использованием двух экспоненциальных распределений и бернуллиевской случайной величины;
- дисперсия и эксцесс вычисляются по формулам с экспоненциальным интегралом.


Если `python` не доступен, можно использовать `py`:

